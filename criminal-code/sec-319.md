# 319. Imitation of forged document, etc., need not be perfect
For the purposes of the provisions of this Code relating to the forgery, counterfeiting, falsifying, uttering, dealing with, using or possessing of any document, stamp, die or coin, it is not necessary that the document, stamp, die or coin, should be so complete, or should be intended to be made so complete, or should be capable of being made so complete, as to be valid or effectual for any of the purposes of a thing of the kind which it purports or is intended to be or to represent, or as to deceive a person of ordinary judgement and observation.
