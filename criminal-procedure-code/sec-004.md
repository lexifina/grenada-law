# 4. Application of the Code generally, and of the several parts thereof
(1) Unless the contrary is expressly provided by any statute, the provisions of this Code shall extend and apply to all proceedings which may be taken after the commencement of this Code in respect of summary or indictable offences.
(2) The provisions of this Book shall, unless the contrary is expressly provided or by necessary implication appears to be intended, apply generally to proceedings under this Code.
(3) The provisions of Book II of this Code shall apply only to proceedings in respect of summary offences.
(4) The provisions of Book III of this Code shall apply only to proceedings in respect of indictable offences.
